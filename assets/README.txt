One subfolder per car, named like the car's "folder" value in js/cars.js:

assets/Bianchina-Red-Ferrara/
  Bianchina-Red-Ferrara-01-0300.webp
  Bianchina-Red-Ferrara-01-0600.webp
  Bianchina-Red-Ferrara-01-1200.webp
  Bianchina-Red-Ferrara-01-1920.webp   (optional, then add 1 to "hi" in cars.js)
  Bianchina-Red-Ferrara-02-0300.webp ...

Photo 01 is the cover shown on the home page. Folder and file names are case-sensitive on Cloudflare and GitHub.
Every photo needs the 0300, 0600 and 1200 versions.
